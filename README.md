# swift-rfc-1035

Domain model for RFC 1035, Domain Names - Implementation and Specification: `RFC_1035.Domain` and its `Label`s (the section 2.3.1 preferred syntax through `init(_:)`, arbitrary section 3.1 octets through `Label(octets:)` with the section 5.1 escaping in `rawValue`), `Message`, `Header`, `Question`, `ResourceRecord` with its typed `Data` (A, NS, CNAME, PTR, MX, TXT, SOA, opaque), `CharacterString`, `RecordType` and `RecordClass`. The wire and presentation coders live in swift-rfc-1035-coder; Apple Foundation bridging (`Codable`) lives in the `RFC 1035 Foundation Integration` target.
